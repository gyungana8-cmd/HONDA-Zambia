# HONDA Zambia — Motorcycle Hire Prototype

A responsive, mobile-first web prototype for a Zambia-focused motorcycle hire marketplace.

## Included
- Rider and owner modes
- Sample motorcycle listings with category, location and daily ZMW rates
- Search and filters
- Hire request form with estimated total
- Owner listing enquiry form
- Local browser storage for demo hire requests

## Run
Open `index.html` in a modern browser. No build step or package installation is required.

## Important prototype limitations
This is a front-end demonstration, not a production booking service. Demo requests are saved only in the current browser. There is no live account system, server database, identity/licence verification, GPS tracking, messaging, payment processing or owner notification.

Before launch in Zambia, implement a secure backend and test:
- Rider/owner authentication and role permissions
- NRC/identity and driving-licence verification
- Motorcycle ownership and roadworthiness/document checks
- Booking acceptance, cancellation and handover records
- Secure payment integration and clear fees/refunds
- Privacy, data protection, dispute handling and support
- Emergency/safety procedures and audit logs

## Deploy
Can be hosted as a static site using GitHub Pages from the `main` branch, repository root.
