# TWENDE Africa's Talking SMS OTP setup

## 1. Apply the database SQL once
Open the Supabase project SQL Editor and run the complete contents of `supabase/phone_otp_setup.sql`.

## 2. Confirm Edge Function secrets
In Supabase Project Settings / Edge Function Secrets, confirm these names exist:
- `AT_API_KEY` — your Africa's Talking production API key
- `AT_USERNAME` — `twendezambia`

Do not put either value in browser code or GitHub source files.

## 3. Add a GitHub Actions secret for deployment
In GitHub repository Settings → Secrets and variables → Actions, add:
- Name: `SUPABASE_ACCESS_TOKEN`
- Value: a Supabase personal access token generated by the project owner

The project reference is already configured in the workflow and is not a secret.

## 4. Deploy the two functions
Open the repository Actions tab and run **Deploy TWENDE SMS Edge Functions** using **Run workflow**.

The workflow deploys:
- `send-sms-otp`
- `verify-sms-otp`

## 5. Build the updated Android app
After deployment and SQL setup, run the existing Android APK build workflow to package the updated passenger phone-verification screens.

## Important
- Live SMS requires an active Africa's Talking production application, sufficient account balance, and an approved sender ID or permitted default sender for Zambia.
- The app uses the Africa's Talking live SMS endpoint.
- Do not share API keys, Supabase access tokens, or service-role keys in screenshots or chat.
